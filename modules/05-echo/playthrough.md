# Echo — Example Playthrough

**Setup**  
Tracks: Integrity 6 | Mind 6 | Hope 4  
Draft Stability: 0  
Zone: Crew Cabin

**Opening**  
Woke again. Clocks still don’t agree. There are entries in this journal I don’t remember writing. One of them is dated six hours from now. It uses my phrasing. The ship is quiet. Waiting to see what this version does. I think the review is almost over.

**Cycle 1**  
Card 4♦ (Low)  
Minor system flicker. Clocks desync by nine seconds then correct.  
*Log:* Same calibration drift as last time. Noted. Stability 0.

**Cycle 2 — Required Threat**  
Card 7♥ → Clean  
Forced contradiction: I remember sealing the Laboratory door from the inside. Every previous entry says I never went there.  
Journal Interaction: Contradict. Stability stays low.  
*Log:* I remember locking myself in the Lab. The journal says I never went. I wrote against the new memory.

**Cycle 3**  
Card 9♣ (Ship card, Stability 0 → severe toll)  
Roll 4. –1 Mind + severe retaliation (forced minor alteration).  
*Log:* The ship punished the rejection. It gave me knowledge I didn’t earn. Mind 5.

**Cycle 4**  
Card 6♠ → Clean (still pays ship toll at low Stability)  
–1 Mind. Doors cycle in the rhythm of the rejected memory.  
Moved toward Airlock.  
*Log:* It’s still using the discarded material as a probe. Mind 4.

**Cycle 5**  
Card Ace of Clubs  
Roll 3. Heavier toll. –1 Mind, –1 Hope. Ship begins final evaluation language.  
*Log:* It asked if this version was ready for archival review. I said I was ready for release instead. Mind 3, Hope 3.

**Cycle 6**  
Reached Airlock. Chose Trick path (low Stability).  
Automatic Trick cost: –1 Mind → Mind 2.  
Final roll 5 → Ambiguous / contaminated success.

**Final Log**  
Hatch open. I left the journal behind with every contradiction still visible. The ship let this draft go. I still remember sealing a Laboratory door that the records say I never approached. I do not know which memories are mine and which were trial material. But I am no longer aboard. That is the only fact I trust.

**Final State:** Mind 2 | Contaminated Trick release
